## Запуск

Для управления сервисом используются скрипты

**start-app.sh** для поднятия контейнеров в docker и запуска сервиса.<br>
Запуск:
```
sh start-app.sh
```

**remove-app.sh** для остановки сервиса и удаления контейнеров.<br>
Запуск:
```
sudo remove-app.sh
```
